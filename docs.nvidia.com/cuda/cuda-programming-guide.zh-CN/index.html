CUDA 编程指南#

CUDA Graph CUDA warp

CUDA 是 NVIDIA 开发的并行计算平台和编程模型，可通过利用 GPU 的强大功能显着提高计算性能。它允许开发者加速计算密集型应用程序，广泛应用于深度学习、科学计算和高性能计算（HPC）等领域。

本 CUDA 编程指南是关于 CUDA 编程模型以及如何使用 CUDA 平台编写在 GPU 上执行的代码的官方综合资源。本指南涵盖了从 CUDA 编程模型和 CUDA 平台到语言扩展的详细信息以及如何使用特定硬件和软件功能的所有内容。本指南为新开发人员提供了学习 CUDA 的途径，并且还为开发人员使用 CUDA 构建应用程序提供了重要资源。

本指南的组织结构

即使对于主要使用库、框架或 DSL 的开发人员来说，了解 CUDA 编程模型以及 GPU 如何执行代码对于了解抽象层背后发生的情况也很有价值。 本指南以一章开头 CUDA编程模型 超越任何特定的编程语言，适用于任何有兴趣了解 CUDA 工作原理的人，甚至非开发人员。

该指南分为五个主要部分：

  • 第 1 部分：简介和编程模型摘要

    • 与语言无关的 CUDA 编程模型概述以及 CUDA 平台的简要介绍。

    • 本节适合任何想要了解 GPU 以及在 GPU 上执行代码的概念的人，即使他们不是开发人员。

  • 第 2 部分：在 CUDA 中对 GPU 进行编程

    • 使用 CUDA C++ 编程 GPU 的基础知识。

    • 本节适合任何想要开始 GPU 编程的人阅读。

    • 本节的目的是指导性的，而不是完整的，并教授 CUDA 编程最重要和最常见的部分，包括一些常见的性能注意事项。

  • 第 3 部分：高级 CUDA

    • 引入了 CUDA 的一些更先进的功能，这些功能既可以实现细粒度控制，又可以有更多机会最大限度地提高性能，包括在单个应用程序中使用多个 GPU。

    • 本节以 浏览第 4 部分中介绍的功能 简要介绍了每个功能的用途和功能，并按开发人员发现每个功能有用的时间和原因排序。

  • 第 4 部分：CUDA 特性

    • 本节完整介绍了特定 CUDA 功能，例如 CUDA 图形、动态并行性、与图形 API 的互操作性以及统一内存。

    • 当需要了解特定 CUDA 功能的完整情况时，应查阅本节。在可能的情况下，我们已在前面的部分中注意介绍和激发本节中涵盖的功能。

  • 第 5 部分：技术附录

    • 技术附录提供了一些关于 CUDA 的 C++ 高级语言支持、硬件特定规范和其他技术规范的参考文档。

    • 本节旨在作为 CUDA 元素的语法、语义和技术行为的具体描述的技术参考。

第 1-3 部分为刚接触 CUDA 的开发人员提供了指导性学习体验，同时也为任何经验水平的 CUDA 开发人员提供了有用的见解和更新信息。

第 4 部分和第 5 部分提供了有关特定功能和详细主题的大量信息，旨在为在编写 CUDA 应用程序时需要了解更多详细信息的开发人员提供精心策划、组织良好的参考。
