深入了解 Google 的第一个张量处理单元 (TPU)

2017 年 5 月 12 日
佐藤和

云人工智能开发者倡导者

克里夫·杨

谷歌大脑软件工程师

有一个共同的线程连接谷歌服务，如谷歌搜索、街景、谷歌照片和谷歌翻译：它们都使用谷歌的张量处理单元（TPU）来加速幕后的神经网络计算。

谷歌在印刷电路板上的第一个张量处理单元（TPU）（左）；部署在 Google 数据中心的 TPU（右）

我们 去年发布了TPU 最近跟进了 详细研究 其性能和架构。简而言之，我们发现 TPU 的性能比当代 CPU 和 GPU 高出 15-30 倍，每瓦性能高出 30-80 倍。这些优势有助于谷歌的许多服务以可承受的成本大规模运行最先进的神经网络。在这篇文章中，我们将深入研究 Google TPU 内部的技术，并讨论它如何提供如此出色的性能。

TPU 之路

尽管谷歌考虑建立一个 专用集成电路 早在 2006 年，我们就开始为神经网络设计专用集成电路（ASIC），但到了 2013 年，情况变得紧急。就在那时，我们意识到神经网络快速增长的计算需求可能需要我们将运营的数据中心数量增加一倍。

通常，ASIC 开发需要几年时间。然而，就 TPU 而言，我们仅用了 15 个月的时间就设计、验证、构建了处理器并将其部署到我们的数据中心。 Norm Jouppi，TPU 项目的技术负责人（也是该项目的主要架构师之一） MIPS处理器）这样描述冲刺：

我们进行了非常快速的芯片设计。这确实非常了不起。我们开始运送第一块芯片，没有修复错误或更改掩模。考虑到我们在构建芯片时招聘了团队，然后招聘了 RTL（电路设计）人员，并急于招聘设计验证人员，整个过程非常忙碌。

在推特上转发这句话

（从 首次深入了解谷歌的TPU架构，下一个平台）

TPU ASIC 采用 28nm 工艺打造，运行频率为 700MHz，运行时功耗 40W。由于我们需要尽快将 TPU 部署到 Google 现有的服务器上，因此我们选择将处理器封装为外部加速卡，适合 SATA 硬盘插槽以进行直接安装。 TPU 通过 PCIe Gen3 x16 总线连接到主机，提供 12.5GB/s 的有效带宽。

使用神经网络进行预测

为了理解我们为什么这样设计 TPU，让我们看一下运行简单神经网络所涉及的计算。

TensorFlow Playground 上的双螺旋问题 (点击这里 尝试一下）

TensorFlow Playground 上的此示例训练神经网络，根据训练数据集将数据点分类为蓝色或橙色。 （看这个帖子 了解有关此示例的更多信息。）运行经过训练的神经网络以使用标签对数据进行分类或估计一些缺失值或未来值的过程称为 推理。为了进行推理，神经网络中的每个神经元都会执行以下计算：

  • 乘 输入数据 (x) 和权重 (w) 表示信号强度
  • 添加 将神经元状态聚合为单个值的结果
  • 申请一个 激活 函数(f)（例如 恢复, 乙状结肠, 腥 或其他）来调节人工神经元的活动。

神经网络获取输入数据，将它们与权重矩阵相乘并应用激活函数​

例如，如果您有三个输入和两个具有完全连接的单层神经网络的神经元，则必须在权重和输入之间执行六次乘法，并将乘法按两组三项相加。这个乘法和加法序列可以写成 矩阵乘法。然后，该矩阵乘法的输出由激活函数进一步处理。即使在使用更复杂的神经网络模型架构时，矩阵相乘通常也是运行经过训练的模型中计算量最大的部分。

在生产规模上您需要多少次乘法运算？ 2016 年 7 月，我们调查了 Google 生产服务中的 6 个具有代表性的神经网络应用，并总结了每个神经网络架构中的权重总数。您可以在下表中看到结果。

正如您在表中看到的，每个神经网络中的权重数量从 500 万到 1 亿不等。每个预测都需要许多步骤，将处理后的输入数据乘以权重矩阵并应用激活函数。

总的来说，这是一个巨大的计算量。作为第一个优化，我们不是在 CPU 或 GPU 上使用普通的 32 位或 16 位浮点运算执行所有这些数学运算，而是应用一种称为量化的技术，该技术允许我们使用整数运算。这使我们能够减少使用神经网络模型进行有用预测所需的内存和计算资源总量。

神经网络中的量化

如果外面下雨，你可能不需要确切地知道每秒有多少水滴落下——你只需要知道雨是小雨还是大雨。同样，神经网络预测通常不需要 32 位甚至 16 位数字的浮点计算精度。经过一些努力，您也许能够使用 8 位整数来计算神经网络预测，并且仍然保持适当的准确度。

量化是一种优化技术，它使用 8 位整数来近似预设最小值和最大值之间的任意值。有关更多详细信息，请参阅 如何使用 TensorFlow 量化神经网络.

TensorFlow 中的量化

量化是降低神经网络预测成本的强大工具，相应的内存使用量减少也很重要，特别是对于移动和嵌入式部署。例如，当您将量化应用于 盗梦空间流行的图像识别模型，它从 91MB 压缩到 23MB，大约是原始大小的四分之一。

能够使用整数而不是浮点运算大大减少了 TPU 的硬件占用空间和能耗。 TPU 包含 65,536 个 8 位整数乘法器。在云环境中广泛使用的流行 GPU 包含数千个 32 位浮点乘法器。只要您能用 8 位满足应用的精度要求，最高可达 25倍 或更多乘数。

RISC、CISC 和 TPU 指令集

可编程性是 TPU 的另一个重要设计目标。 TPU 并非旨在仅运行一种类型的神经网络模型。相反，它的设计足够灵活，可以加速运行许多不同类型的神经网络模型所需的计算。

大多数现代 CPU 都深受 精简指令集计算机 (RISC) 设计风格。对于 RISC，重点是定义大多数应用程序常用的简单指令（例如加载、存储、加法和乘法），然后尽快执行这些指令。我们选择了 复杂指令集计算机 (CISC) 相反，风格作为TPU指令集的基础。 CISC 设计侧重于实现使用每条指令运行更复杂任务（例如多次计算乘法和加法）的高级指令。我们来看一下TPU的框图。

TPU 框图

TPU 包括以下计算资源：

  • 矩阵乘法器单元 (MXU)：65,536 个 8 位乘加单元用于矩阵运算
  • 统一缓冲区 (UB)：24MB SRAM，用作寄存器
  • 激活单位（AU）：硬连线激活函数
为了控制 MXU、UB 和 AU 如何进行操作，我们定义了十几个专门为神经网络推理设计的高级指令。下面重点介绍了其中的五项操作。

TPU指令功能
读主机内存从内存中读取数据
读取权重从内存中读取重量
矩阵乘法/卷积将数据和权重相乘或卷积，累加结果
激活应用激活函数
写入主机内存将结果写入内存

该指令集重点关注我们之前提到的神经网络推理所需的主要数学运算：在输入数据和权重之间执行矩阵乘法并应用激活函数。

规范说：

神经网络模型由不同大小的矩阵乘法组成——这就是形成全连接层的原因，或者在 CNN 中，它往往是更小的矩阵乘法。这个架构就是做这些事情——当你累积了所有的部分和并从累加器输出时，一切都会通过这个激活管道。非线性使其成为神经网络，即使它主要是线性代数。”（摘自《首次深入了解 Google 的 TPU 架构，下一代平台》）

简而言之，TPU 设计封装了神经网络计算的本质，并且可以针对多种神经网络模型进行编程。为了对其进行编程，我们创建了一个编译器和软件堆栈，将 TensorFlow 图的 API 调用转换为 TPU 指令。

矩阵乘法器单元的并行处理

典型的 RISC 处理器提供简单计算的指令，例如乘法或加法。这些就是所谓的 标量处理器，因为它们用每条指令处理单个操作（=标量操作）。

尽管 CPU 以千兆赫范围内的时钟速度运行，但通过一系列标量运算执行大型矩阵运算仍然需要很长时间。提高此类大型矩阵运算性能的一种有效且众所周知的方法是通过 矢量处理，其中同时对大量数据元素同时执行相同的操作。 CPU 包含指令集扩展，例如 上证所 和 AVX 表达此类向量运算。 GPU 的流式多处理器 (SM) 实际上是矢量处理器，单个 GPU 芯片上有许多此类 SM。支持矢量处理的机器可以在单个时钟周期内处理数百到数千个操作。

就 TPU 而言，谷歌将其 MXU 设计为 矩阵处理器 那个过程 数十万次运算（=矩阵运算） 在单个时钟周期内。可以将其想象为一次打印一个字符、一次一行、一次一页的文档。

使用矩阵处理器就像一次打印整页文档，而不是逐字符或逐行打印文档

TPU 的核心：脉动阵列

为了实现如此大规模的矩阵处理器，MXU 采用了与典型 CPU 和 GPU 截然不同的架构，称为 脉动阵列。 CPU 设计用于运行几乎所有计算；它们是通用计算机。为了实现这种通用性，CPU 将值存储在寄存器中，程序告诉算术逻辑单元 (ALU) 要读取哪些寄存器、要执行的操作（例如加法、乘法或逻辑 AND）以及要将结果放入哪个寄存器。程序由一系列读/操作/写操作组成。所有这些支持通用性的功能（寄存器、ALU 和编程控制）都会在功耗和芯片面积方面产生成本。

CPU 和 GPU 在每次操作时通常会花费精力来访问多个寄存器。脉动阵列将多个 ALU 链接在一起，重用读取单个寄存器的结果。

然而，对于 MXU，矩阵乘法会多次重复使用两个输入作为生成输出的一部分。我们可以读取每个输入值一次，但可以将其用于许多不同的操作，而无需将其存储回寄存器。电线仅连接空间上相邻的 ALU，这使得它们短且节能。 ALU 仅以固定模式执行乘法和加法，这简化了它们的设计。

使用脉动数组将输入向量乘以权重矩阵

该设计被称为收缩式，因为数据以波浪形式流过芯片，让人想起心脏泵血的方式。 MXU 中特殊类型的脉动阵列针对执行矩阵乘法时的功耗和面积效率进行了优化，但不太适合通用计算。它做出了工程上的权衡：限制寄存器、控制和操作灵活性，以换取效率和更高的操作密度。

使用脉动数组将输入矩阵乘以权重矩阵

TPU 矩阵乘法单元具有脉动阵列机制，包含 256 × 256 = 总共 65,536 个 ALU。这意味着 TPU 每个周期可以处理 65,536 个 8 位整数的乘法和加法。由于 TPU 的运行频率为 700MHz，因此 TPU 可以计算 65,536 × 700,000,000 = 46 × 1012 乘法和加法运算或每秒 92 Teraops (92 × 1012）在矩阵单元中。

TPU 的矩阵乘法器单元 (MXU)

最小化和确定性设计

设计针对神经网络推理进行优化的新处理器的另一个显着好处是，您可以在设计中实现极致简约。正如我们在 TPU纸:

与 CPU 和 GPU 相比，单线程 TPU 不具备任何复杂的微架构功能，这些功能会消耗晶体管和能量来改善平均情况，但不会改善 99% 的情况：无缓存、分支预测、乱序执行、多处理、推测性预取、地址合并、多线程、上下文切换等。极简主义是特定领域处理器的优点。”（第 8 页）

在推特上转发这句话

由于 CPU 和 GPU 等通用处理器必须在各种应用程序中提供良好的性能，因此它们已经发展了无数复杂的、面向性能的机制。副作用是，这些处理器的行为可能难以预测，这使得很难保证神经网络推理的一定延迟限制。相比之下，TPU的设计严格 最小和确定性 因为它必须运行 一次只有一项任务：神经网络预测。您可以从 TPU 模具的平面图中看到它的简单性。

TPU 芯片的平面图（黄色 = 计算，蓝色 = 数据，绿色 = I/O，红色 = 控制）

如果将其与 CPU 和 GPU 的平面图进行比较，您会发现 CPU 和 GPU 的红色部分（控制逻辑）要大得多（因此更难以设计），因为它们需要实现上述复杂的构造和机制。在 TPU 中，控制逻辑极少，仅占芯片面积的 2% 以下。

更重要的是，尽管 TPU 芯片拥有更多的运算单元和更大的片上存储器，但其尺寸只有其他芯片的一半。由于芯片的成本是面积的函数3 - 更多的 每个硅片上的芯片更小 小芯片的产量更高，因为它们不太可能出现制造缺陷* — 芯片尺寸减半可将芯片成本降低大约 8 倍（23).

借助 TPU，我们可以轻松准确地估计运行神经网络并进行预测所需的时间。这使我们能够以接近峰值的芯片吞吐量运行，同时对几乎所有预测保持严格的延迟限制。例如，尽管有严格的 7毫秒 在上述 MLP0 应用中的限制，TPU 提供 15–30X 比当代 CPU 和 GPU 更高的吞吐量。

我们使用神经网络预测来支持面向最终用户的产品和服务，众所周知，如果服务响应时间过长，用户就会变得不耐烦。因此，对于 MLP0 应用程序，我们将 99% 的预测延迟限制在 7 毫秒左右，以实现基于 TPU 的 Google 服务始终如一的快速用户体验。以下是在延迟限制下的六个神经网络应用程序中 TPU 与当代 CPU 和 GPU 之间的整体性能（每秒预测）比较。在最引人注目的情况下，与 CNN1 应用程序的 CPU 相比，TPU 提供了 71 倍的性能。

神经特定架构

在这篇文章中，我们看到了TPU表现出色的秘诀在于它对神经网络推理的执着。当我们决定专注于神经网络推理时，量化选择、CISC 指令集、矩阵处理器和最小设计都成为可能。谷歌对投资 TPU 充满信心，因为我们看到神经网络正在推动计算领域的范式转变，并且我们预计 TPU 将成为未来几年快速、智能和负担得起的服务的重要组成部分。
